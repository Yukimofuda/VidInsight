# VidInsight Day 2 — 2026-09-04

## Goal
Complete the video-ingestion baseline:

Video upload → FFmpeg → 16 kHz mono WAV → faster-whisper → timestamped transcript → JSON persistence → FastAPI → Streamlit display.

## Definition of Done
- `/health` returns `2026-09-04`.
- `POST /api/videos/process` accepts MP4/MOV/MKV/AVI/WEBM/MP3/WAV/M4A.
- FFmpeg produces `storage/audio/<video_id>.wav` at 16 kHz mono PCM.
- faster-whisper returns language, full text and segment-level timestamps.
- JSON is saved under `storage/transcripts/<video_id>.json`.
- `GET /api/videos/{video_id}/transcript` can read the saved result.
- Streamlit can upload/play media and display transcript/timestamps.
- Invalid extensions return HTTP 400.
